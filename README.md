# PCS Landing

Премиальный светлый лендинг для People Counter System.

## Запуск

```bash
cd landing
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```

Статика в `dist/` — можно деплоить на Vercel, Netlify или GitHub Pages.

## Стек

- Vite + React + TypeScript
- TailwindCSS (Editorial Light design system)
- Framer Motion
- Lucide React
